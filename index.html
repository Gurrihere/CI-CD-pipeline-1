About

Pragmatic engineering, measured in outcomes.

I'm Gurpreet — a software engineer who enjoys the unglamorous parts of building products: the deployment pipeline that never flakes, the service that degrades gracefully, the log line that tells you exactly what went wrong.

My work sits where application code meets infrastructure. That usually means designing APIs, containerising services, wiring up automated testing and release pipelines, and setting up the observability needed to operate a system with confidence.

I care about clear writing as much as clear code. Good documentation, honest post-mortems and small reviewable pull requests tend to outperform heroics.
